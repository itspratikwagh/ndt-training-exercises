# Epoch 650 lesson videos — first drafts (parked)

Rendered 1080p MP4s with burned-in subtitles and no audio, made from the first version of the four
Epoch 650 trainer lessons. Parked here so they aren't lost. They will be revised once the
interactives are final, then re-rendered with `video/record.cjs` and their `.srt` and voice-over
scripts regenerated with `video/export-captions.cjs`.

This branch only stores the drafts and is not meant to be merged into `main`.
