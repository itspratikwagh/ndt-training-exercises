Process Control · Daily System Check

Before any part runs: prove the line works

Every shift, a TAM panel (PSM-5) goes through the penetrant line like a part. Five star-shaped crack centers — from coarse to very fine — measure the whole system's sensitivity in one shot; the grit-blasted half checks washability.

  • Process the panel, then read it under UV-A against the baseline photo: mark every star you can see, and judge the background.
  • If it doesn't match baseline, the line doesn't run — and your first suspect is the panel itself, not the tank.
  • Each run is a different shift — some days the line is healthy, some days it isn't.
